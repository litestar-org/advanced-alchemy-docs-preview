class advanced_alchemy.base.CommonTableAttributes[source]#

Bases: BasicAttributes

Common attributes for SQLAlchemy tables.

Inherits from BasicAttributes and provides a mechanism to infer table names from class names while respecting SQLAlchemy’s inheritance patterns.

This mixin supports all three SQLAlchemy inheritance patterns: - Single Table Inheritance (STI): Child classes automatically use parent’s table - Joined Table Inheritance (JTI): Child classes have their own tables with foreign keys - Concrete Table Inheritance (CTI): Child classes have independent tables

Variables:

__tablename__ – The inferred table name, or None for Single Table Inheritance children.

advanced_alchemy.base.model_to_dict(instance, exclude=None)[source]#

Convert a mapped model instance to a dictionary.

Works with any SQLAlchemy-mapped model, including: - Advanced Alchemy models (delegates to to_dict()) - SQLModel table=True models (uses mapper-based column iteration) - Any other mapped class

Parameters:

  • instance (ModelProtocol) – A SQLAlchemy-mapped model instance.

  • exclude (set[str] | None) – Optional set of field names to exclude from the output.

Returns:

A dictionary of column names to values.

Return type:

dict[str, Any]
