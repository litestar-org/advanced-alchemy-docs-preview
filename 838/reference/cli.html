CLI Commands#

alchemy#

Advanced Alchemy CLI commands.

Usage

alchemy [OPTIONS] COMMAND [ARGS]...

Options

-c, --config <config>#

Dotted or colon path to SQLAlchemy config(s) or factory callable (env: ALCHEMY_CONFIG)

--validate-config#

Validate configuration before executing migrations

Environment variables

ALCHEMY_CONFIG

Provide a default for --config

advanced_alchemy.cli.discover_config_from_pyproject()[source]#

Find and parse pyproject.toml for Advanced Alchemy CLI configuration.

Walks upward from the current working directory to locate pyproject.toml and parses [tool.advanced-alchemy] (or [tool.advanced_alchemy] / [tool.alchemy]) for the config key.

Returns:

Configured path string (comma-separated when configured as a list), or None when not found.

Return type:

str | None

advanced_alchemy.cli.find_pyproject_toml()[source]#

Walk the filesystem upward from Path.cwd() to find pyproject.toml.

Stops at a .git directory boundary (repository root) or the filesystem root.

Returns:

Path to pyproject.toml, or None if not found.

Return type:

Path | None

advanced_alchemy.cli.parse_pyproject_config(pyproject_path)[source]#

Parse pyproject.toml for Advanced Alchemy CLI configuration.

Checks [tool.advanced-alchemy], [tool.advanced_alchemy], and [tool.alchemy] in order for a config entry.

Parameters:

pyproject_path (Path) – Path to the pyproject.toml file.

Returns:

Config path(s) as a string (converting a list of strings to a comma-separated string), or None if no config is defined.

Raises:

ValueError – If the pyproject.toml file cannot be parsed or the config value is not a string or list of strings.

Return type:

str | None

Resolve configuration asynchronously from a dotted or colon-separated path.

Supports direct config instances, sequences of configs, wrapper objects exposing .config (such as SQLAlchemyInitPlugin or AdvancedAlchemy), synchronous factory callables, and asynchronous coroutine factories.

Returns:

A resolved config instance or list of config instances.

Raises:
