Litestar CLI database group and plugin discovery utilities.

Database Command Group#

litestar database#

Manage SQLAlchemy database components.

Usage

litestar database [OPTIONS] COMMAND [ARGS]...

branches#

Show current branch points in the migration history

Usage

litestar database branches [OPTIONS]

Options

-c, --config <config>#

Dotted or colon path to SQLAlchemy config(s) or factory callable (env: ALCHEMY_CONFIG)

--validate-config#

Validate configuration before executing migrations

--bind-key <bind_key>#

Specify which SQLAlchemy config to use by bind key

--verbose#

Enable verbose output.

Environment variables

ALCHEMY_CONFIG

Provide a default for --config

dump-data#

Dump specified tables from the database to fixture files.

Usage

litestar database dump-data [OPTIONS]

Options

-c, --config <config>#

Dotted or colon path to SQLAlchemy config(s) or factory callable (env: ALCHEMY_CONFIG)

--validate-config#

Validate configuration before executing migrations

--bind-key <bind_key>#

Specify which SQLAlchemy config to use by bind key

--table <table_names>#

Required Name of the table to dump. Multiple tables can be specified. Use ‘*’ to dump all tables.

--dir <dump_dir>#

Directory to save the fixture files. Defaults to WORKDIR/fixtures

--format <file_format>#

Fixture file format.

Default:

'json'

Options:

json | jsonl | csv

--compression <compression>#

Compression applied to each fixture file.

Default:

'none'

Options:

none | gzip | zip

--max-file-size <max_file_size>#

Start a new numbered shard before a file would exceed this on-disk size, in bytes or with a K, M, or G suffix (1024-based), for example 50M.

--max-records <max_records>#

Start a new numbered shard after this many records.

Environment variables

ALCHEMY_CONFIG

Provide a default for --config
