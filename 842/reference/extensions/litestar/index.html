Set up the handler to issue a transaction commit or rollback based on specified status codes :param commit_on_redirect: Issue a commit when the response status is a redirect (3XX) :param extra_commit_statuses: A set of additional status codes that trigger a commit :param extra_rollback_statuses: A set of additional status codes that trigger a rollback :param session_scope_key: The key to use within the application state

Raises:

ValueError – If the extra commit statuses and extra rollback statuses share any status codes

The handler callable

  • config (Optional[Union[SQLAlchemyAsyncConfig, SQLAlchemySyncConfig]]) – The configuration to use for the service.

  • error_messages (Optional[Union[ErrorMessages, EmptyType]]) – The error messages to use for the service.

  • load (Optional[LoadSpec]) – The load spec to use for the service.

  • execution_options (Optional[dict[str, Any]]) – The execution options to use for the service.

  • filters (Optional[FilterConfig]) – The filter configuration to use for the service.

  • uniquify (bool | None) – Whether to uniquify the service.

  • count_with_window_function (bool | None) – Whether to count with a window function.

  • dep_defaults (DependencyDefaults) – The dependency defaults to use for the service.

Create a dependency provider for a service with a configurable session key.

Parameters:

  • service_class (type[AsyncServiceT_co | SyncServiceT_co]) – The service class inheriting from SQLAlchemyAsyncRepositoryService or SQLAlchemySyncRepositoryService.

  • statement (Optional[Select[tuple[ModelT]]]) – An optional SQLAlchemy Select statement to scope the service.

  • config (Optional[Union[SQLAlchemyAsyncConfig, SQLAlchemySyncConfig]]) – An optional SQLAlchemy configuration object.

  • error_messages (Optional[Union[ErrorMessages, EmptyType]]) – Optional custom error messages for the service.

  • load (Optional[LoadSpec]) – Optional LoadSpec for eager loading relationships.

  • execution_options (Optional[dict[str, Any]]) – Optional dictionary of execution options for SQLAlchemy.

  • uniquify (bool | None) – Optional flag to uniquify results.

  • count_with_window_function (bool | None) – Optional flag to use window function for counting.

Returns:

A dependency provider function suitable for Litestar’s DI system.

Return type:

Callable[[…], AsyncGenerator[AsyncServiceT_co, None] | Generator[SyncServiceT_co,None, None]]
