advanced_alchemy.utils.fixtures.open_fixture_sync(fixtures_path, fixture_name)[source]#

Load a JSON, JSONL, or CSV fixture synchronously.

Supports plain files, gzip-compressed files (.gz), and zip archives (.zip). Formats are resolved in priority order: json > jsonl > csv. Both lowercase and uppercase fixture names are checked according to format and compression rules. Text is decoded using utf-8-sig.

Unsharded json fixtures return the decoded top-level JSON value unchanged. Unsharded jsonl and csv fixtures return a list of decoded records or dictionaries.

Parameters:

  • fixtures_path (Union[Path, AsyncPath]) – Directory path containing fixture files. Can be a pathlib.Path or anyio.Path instance.

  • fixture_name (str) – Fixture base name without file extension.

Raises:

  • FileNotFoundError – If no matching fixture file exists.

  • OSError – If an I/O or decompression error occurs while reading the file.

  • ValueError – If a zip archive contains no matching member, a JSONL line contains invalid JSON, or a JSON fixture read as records is not an array.

Returns:

Decoded JSON data or a list of records.

Return type:

Any

Examples

>>> from pathlib import Path
>>> fixtures_path = Path("./fixtures")
>>> data = open_fixture_sync(fixtures_path, "users")
>>> print(data)
[{"id": 1, "name": "Alice"}, {"id": 2, "name": "Bob"}]

Streaming, Writing & Legacy Alias#

advanced_alchemy.utils.fixtures.iter_fixture_sync(fixtures_path, fixture_name, *, batch_size=1000)[source]#

Stream decoded fixture records in non-empty batches synchronously.

Validates batch_size and resolves the fixture file or numbered shards eagerly at call time, then yields non-empty batches of at most batch_size records across shard boundaries. Closing the returned iterator early releases any open file handle immediately.

Parameters:

  • fixtures_path (Union[Path, AsyncPath]) – Directory path containing fixture files. Can be a pathlib.Path or anyio.Path instance.

  • fixture_name (str) – Fixture base name without file extension.

  • batch_size (int) – Maximum number of records per yielded batch. Must be at least 1.

Raises:

  • FileNotFoundError – If no matching fixture file exists.

  • OSError – If an I/O or decompression error occurs while reading a file.

  • ValueError – If batch_size is less than 1, both an unsharded file and numbered shards exist, shard validation fails, a zip archive contains no matching member, a JSONL line contains invalid JSON, or a JSON fixture is not an array.

Returns:

Iterator yielding non-empty lists of records.

Return type:

Iterator[list[Any]]

async advanced_alchemy.utils.fixtures.iter_fixture_async(fixtures_path, fixture_name, *, batch_size=1000)[source]#

Stream decoded fixture records in non-empty batches asynchronously.

Offloads fixture resolution, batch reads, and generator teardown to worker threads via async_(). Validation and resolution run on the first iteration step. Callers exiting early must call aclose() or consume the iterator completely so underlying file handles are closed promptly.

Parameters:

  • fixtures_path (Union[Path, AsyncPath]) – Directory path containing fixture files. Can be a pathlib.Path or anyio.Path instance.

  • fixture_name (str) – Fixture base name without file extension.

  • batch_size (int) – Maximum number of records per yielded batch. Must be at least 1.

Raises:

  • FileNotFoundError – If no matching fixture file exists.

  • OSError – If an I/O or decompression error occurs while reading a file.

  • ValueError – If batch_size is less than 1, both an unsharded file and numbered shards exist, shard validation fails, a zip archive contains no matching member, a JSONL line contains invalid JSON, or a JSON fixture is not an array.

Yields:

list[Any] – Non-empty batch of decoded records.

Return type:

AsyncIterator[list[Any]]

advanced_alchemy.utils.fixtures.write_fixture_sync(
fixtures_path,
fixture_name,
records,
*,
file_format='json',
compression=None,
max_bytes=None,
max_records=None,
)[source]#

Write fixture records synchronously in JSON, JSONL, or CSV format.

Streams encoded records into temporary .tmp files, removes any existing fixture files matching fixture_name across all formats, compressions, and shard layouts upon completion, and atomically renames temporary files into place.

Parameters:

  • fixtures_path (Union[Path, AsyncPath]) – Target directory path for fixture files. Created if it does not exist. Can be a pathlib.Path or anyio.Path.

  • fixture_name (str) – Fixture base name without file extension.

  • records (Iterable[Any]) – Iterable of records to write.

  • file_format ('json' | 'jsonl' | 'csv') – Output format ("json", "jsonl", or "csv").

  • compression (Optional[FixtureCompression]) – Optional compression ("gzip", "zip", or None).

  • max_bytes (Optional[int]) – Optional maximum on-disk byte size per shard. Must be at least 1.

  • max_records (Optional[int]) – Optional maximum record count per shard. Must be at least 1.

Raises:

  • ValueError – If file_format, compression, max_bytes, or max_records is invalid, or if CSV records introduce keys absent from the header.

  • TypeError – If file_format is "csv" and a record is not a mapping.

  • OSError – If writing, deleting stale files, or renaming files fails.

Returns:

Final written fixture paths in shard order.

Return type:

list[Path]

Examples

>>> from pathlib import Path
>>> fixtures_path = Path("./fixtures")
>>> paths = write_fixture_sync(
...     fixtures_path,
...     "users",
...     [{"id": 1, "name": "Alice"}],
...     file_format="jsonl",
...     compression="gzip",
... )

Write fixture records asynchronously in JSON, JSONL, or CSV format.

Streams records from a synchronous or asynchronous iterable in batches of batch_size into temporary .tmp files, offloads writer construction, batch writes, commit, and abort to worker threads via async_(), removes stale fixture files matching fixture_name on completion, and atomically renames temporary files into place.

Parameters:

  • fixtures_path (Union[Path, AsyncPath]) – Target directory path for fixture files. Created if it does not exist. Can be a pathlib.Path or anyio.Path.

  • fixture_name (str) – Fixture base name without file extension.

  • records (Union[Iterable[Any], AsyncIterable[Any]]) – Synchronous or asynchronous iterable of records to write.

  • file_format ('json' | 'jsonl' | 'csv') – Output format ("json", "jsonl", or "csv").

  • compression (Optional[FixtureCompression]) – Optional compression ("gzip", "zip", or None).

  • max_bytes (Optional[int]) – Optional maximum on-disk byte size per shard. Must be at least 1.

  • max_records (Optional[int]) – Optional maximum record count per shard. Must be at least 1.

  • batch_size (int) – Maximum number of records buffered before offloading a batch write to a worker thread. Must be at least 1.

Raises:

  • ValueError – If batch_size, file_format, compression, max_bytes, or max_records is invalid, or if CSV records introduce keys absent from the header.

  • TypeError – If file_format is "csv" and a record is not a mapping.

  • OSError – If writing, deleting stale files, or renaming files fails.

Returns:

Final written fixture paths in shard order.

Return type:

list[Path]

Examples

>>> from pathlib import Path
>>> async def stream_users():
...     yield {"id": 1, "name": "Alice"}
>>> paths = await write_fixture_async(
...     Path("./fixtures"),
...     "users",
...     stream_users(),
...     file_format="jsonl",
...     compression="gzip",
... )
