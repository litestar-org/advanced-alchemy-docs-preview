Cursor Pagination#

Keyset pagination filters, ordering keys, and the token codec hook. See Filtering and Pagination for usage and Schema Conversion & Pagination for the CursorPagination response container.

Filter#

class advanced_alchemy.filters.CursorFilter(
keys,
limit,
cursor=None,
secret=None,
*,
ttl=None,
encrypted=False,
)[source]#

Bases: PaginationFilter

Keyset (cursor) pagination.

Pages by comparing the ordering keys of the last row a client saw instead of skipping rows with OFFSET, so deep pages cost the same as the first and concurrent inserts do not shift later pages. The model’s primary key is appended as the final key, in the direction of the last declared key, so every row has a unique position.

The filter owns ordering and limits: it replaces any ORDER BY, LIMIT, and OFFSET on the statement and fetches limit + 1 rows to learn whether another page exists. Build the response with to_schema(..., pagination_type="cursor") or build_page(), which drop the extra row.

Parameters:

  • keys (tuple[CursorKey, ...]) – Ordering keys; see CursorKeys. An empty sequence pages by primary key.

  • limit (int) – Page size.

  • cursor (str | None) – Token from a previous page, or None for the first page.

  • secret (str | bytes | None) – Key used to sign tokens, or to encrypt them when encrypted is set.

  • ttl (float | timedelta | None) – Token lifetime in seconds or as a timedelta.

  • encrypted (bool) – Encrypt tokens so clients cannot read the key values.

Raises:

  • ValueError – The keys, limit, secret, or ttl are invalid.

  • InvalidCursorError – cursor is malformed, tampered with, expired, or issued for a different ordering.

token_options(defaults=None, *, require_secret=False)[source]#

Resolve the secret, lifetime, and encryption flag for issued and accepted tokens.

Each option comes from the filter configuration, then defaults. The secret then falls back to the CURSOR_SECRET_ENV_VARS environment variables. Tokens are keyed with a value derived from the secret, so the secret itself never signs a token.

Parameters:

  • defaults (CursorDefaults | None) – Application-wide options.

  • require_secret (bool) – Refuse to issue or accept unsigned tokens.

Returns:

The token key, lifetime, and encryption flag.

Raises:

ImproperConfigurationError – No secret is configured and one is required or encryption is enabled.

Return type:

tuple[bytes | None, float | timedelta | None, bool]
